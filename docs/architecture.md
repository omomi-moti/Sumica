# アーキテクチャ上の決定

実装前の設計メモ（2026-08-16 時点）。実装しながら変わりうる。
変わったらこのファイルを更新する。行動ルールは [CLAUDE.md](../CLAUDE.md) 側。

## 汚れ度は永続化しない

`Area.lastVerifiedCleanAt` からの純粋関数で毎回算出する。

この設計により**閾値に到達する時刻を逆算できる**ため、バックグラウンド処理を持たずローカル通知のスケジュールだけで完結する。汚れ度そのものを保存すると、保存値を定期的に更新する仕組みが必要になり、これが成立しなくなる。

## 現在時刻は引数で受け取る

`Domain/` 内の関数は `Date()` を呼ばない。

上記の「逆算」も、テストも、時刻を注入できることが前提になっている。`Date()` を内部で呼ぶと、任意の経過時間に対する検証ができなくなる。

## 描画層は差し替え可能にする

汚れの計算・粒子の配置・モップの経路はすべて `Domain/` に置き、描画層には持たせない。

将来 2D から 3D へ差し替える余地を残すため。ただし現時点で作るのは 2D（`Canvas2DRoomRenderer`）のみで、3D 用の抽象化を先に用意することはしない。

## 区画のポリゴンは凸多角形のみ

扇状分割（fan triangulation）で三角形化しているため、**凹形状は破綻する**。

L 字型の部屋などを扱いたくなった場合は、凸多角形の組み合わせとして表現するか、三角形化アルゴリズムを変更する必要がある。
